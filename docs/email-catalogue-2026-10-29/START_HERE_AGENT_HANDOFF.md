## Evidence limits

Live plugin versions were inventoried October 29. Matching local versions do not prove identical deployed files. Saved email subjects, MailPoet campaigns, translations, snippets and provider-managed emails need a configuration audit. Some source links point to Windows paths and serve as provenance; use the embedded excerpts when those paths are unavailable. Reconcile the current deployed source with repository versions before editing.

Do not interpret an existing sender as enabled, a queued message as delivered, an approved reimbursement as paid, or this documentation publication as a live site change. Dokan Pro is removed; only Dokan Lite remains.

## Copy/paste assignment for another agent

Read the current catalogue and modernization specification linked above. Audit current deployed sender versions and saved settings, then implement the specification using existing authoritative event/outbox pipelines. Preserve financial controls and private seller/order data. Produce replacement subjects, concise bodies, mobile HTML/plain-text templates and the missing lifecycle notifications where supported. Test with synthetic fixtures and approved test inboxes. Do not send historical or unsolicited customer mail, change money movement, enable paused financial features, or claim guaranteed Gmail inbox placement. Deliver an implementation report separating code, tests, deployment, enabled features and actual delivery evidence.
