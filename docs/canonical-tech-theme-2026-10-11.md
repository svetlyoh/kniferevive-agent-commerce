# Canonical Tech theme

`theme-overlays/kniferevive/assets/css/tech-theme.css` is the canonical Tech palette, navigation, notices, filter, form and footer stylesheet. Shared component layout remains in existing files. Tech-specific black navigation and announcement rules have been removed from navigation.css, annex.css and metacategories.css rather than retained as competing copies. Tech layout variables are overridden in the canonical file; the component defaults remain available to non-Tech carousels.

`inc/tech-theme.php` supplies one `kr_is_tech_context()` predicate for the `kr-tech-theme` body class and conditional enqueue. It covers the Technology Trade Desk, products assigned anywhere under Tech, native category descendants at any depth, collection groups whose native category slugs belong to Tech, filtered Google subtypes, pages beneath the Trade Desk, and pages containing its shortcode or assigned a Tech term. New native descendants and new registered Tech collection groups inherit the stylesheet automatically. The existing Dell brand presentation is preserved. Ordinary unassociated pages must be placed beneath the Tech page, assigned to the Tech tree, or use the Tech shortcode to receive the theme.

The canonical stylesheet loads after shared navigation, Annex, footer and collection component styles. This changes presentation only; listing data and feed IDs are unaffected. Theme release: 2026.10.11.11. Validation: 39 route/class/enqueue assertions and PHP lint, verified runtime ZIP, plus live landing, product, native child category, filtered collection, drawer and non-Tech control checks.
