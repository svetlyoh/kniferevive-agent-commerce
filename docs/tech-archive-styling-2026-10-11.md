# Black navigation on Tech collections

Theme 2026.10.11.9 extends the existing black header, search, drawer and Annex menu rules to `kr-ai-catalog`, the class used by Tech collection archives and Google subtype filters. Previously those archives had dark content and light navigation, leaving pale menu text on a white surface.

The catalog body, sorting control and brand-filter surfaces also use black backgrounds with readable light text. The drawer close button remains visible. At the existing 1,360px breakpoint, Tech archives hide the secondary Sell button like the Trade Desk, preventing the header from overflowing.

Deployment uses the existing native WordPress theme replacement. Product classifications, inventories and feed metadata are unchanged. Verification covers the reported AI-Tech/Desktop Computers and Tech/Mobile Phones URLs, open navigation and Shop Categories submenus, plus a normal non-Tech category directory as a styling control. The complete runtime ZIP passes the existing source/package verification; this CSS correction does not rerun unrelated product/import tests.
